
# Política de Privacidad — ControlAsistencia

**Última actualización: 25 de octubre de 2026

ControlAsistencia es una aplicación diseñada con un enfoque prioritario en la privacidad y la protección de datos de docentes y alumnos.

1. Recopilación de Datos
ControlAsistencia NO recopila, transmite, vende ni almacena ningún tipo de información personal, nombres de alumnos, registros de asistencia o datos de uso en servidores externos ni a terceros.

2. Almacenamiento Local
Toda la información ingresada en la aplicación (grupos, listas de alumnos, estados de asistencia y preferencias de tema) se almacena de forma exclusivamente local en su dispositivo iOS a través de los marcos de trabajo seguros de Apple (SwiftData y UserDefaults).

3. Autenticación Biométrica (Face ID / Touch ID)
Si activa la función de protección de acceso en la aplicación, la verificación biométrica es gestionada de manera local por el sistema operativo iOS (LocalAuthentication). ControlAsistencia no tiene acceso en ningún momento a sus datos biométricos ni a sus claves de seguridad.

4. Copias de Seguridad
Las copias de respaldo generadas por el usuario son archivos locales que el usuario gestiona libremente a través de las opciones de exportación del sistema (como iCloud Drive o almacenamiento local).
